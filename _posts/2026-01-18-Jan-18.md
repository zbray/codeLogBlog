## Step 2: Add a CSS grid layout

Next is applying some CSS rules to reset the default styles

```css
#movies {
  list-style-type: none;
  padding: 0;
  margin: 0;

  figure {
    margin: 0;
  }
}
```

> Note:
>
> - `list-style-type: none;` removes the bullet points that appear before list items in the `ul`
> - `padding: 0;` and `margin: 0;` removes the padding and margin around the list that browsers could add.
> - `figure { margin: 0; }` this rule, nested inside `#movies` removes the default margin from figure elements ensuring the images and captions sit flush against their containers with no extra spacing that browsers could add.

Next step is to arrange the list item elements into a grid using [CSS Grid](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Grid_layout). I also need to apply a width to these images because browsers will default their dimensions to their original size.

```css
#movies {
  display: grid;
  grid-template-columns: repeat(auto-fill, 200px);
  column-gap: 1em;
  row-gap: 2em;

  img {
    width: 100%;
  }
}
```

> Note:
>
> - `display: grid;` turns the `#movies` element into a grid container and the children of that element (our movie figures) into grid items
> - `grid-template-columns` specifies the size of the columns and how many columns in a grid layout.
> - `repeat(auto-fill, 200px);` tells the browser to automatically generate as many columns as can fit into the container's width while giving each column 200px of width.
> - `column-gap: 1em:` and `row-gap: 2em;` will require 1em gap between each column and 2em gap between each row.
