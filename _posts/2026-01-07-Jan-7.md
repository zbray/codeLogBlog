## 2026-01-07

### Links

Links to pages on other websites on the internet are called **absolute links**.

Links to pages within our own website are called **relative links**.

#### Absolute links

Absolute links will always contain the **scheme and domain** (see Anatomy of a URL below) of the destination.

#### Anatomy of a URL

(source: [mdn](https://developer.mozilla.org/en-US/docs/Learn_web_development/Howto/Web_mechanics/What_is_a_URL#scheme))

```html
http://www.example.com:80
```

***Scheme***: (`http`) The scheme of a URL indicates the **protocol** (set method for exchanging or transferring data around a computer network) the browser must use to request the resource. Most websites use the protocol HTTPS or HTTP (unsecured version)

***Authority***: (`www.example.com:80`) The authority is separated from the **scheme** by the character pattern `://`.  If present the authority includes both the **domain** (`www.example.com`) and the **port** (`80`) separated by a colon. (`:`)

- The **domain** of a URL indicates which Web server is being requested (`www.example.com`) Usually this is a domain name but it can also be an IP Address.
- The port indicates the technical "gate" used to access the resources on the web server. It is usually omitted if the web server uses the standard ports of the HTTP protocol (80 for HTTP and 443 for HTTPS) to grant access to its resources. Otherwise it is mandatory.

Note: the separator between the scheme and authority is `://` The colon separates the scheme from the next part of the URL while `//` indicates the next part of the URL is the authority.

#### Relative links

Relative links do not include the domain name since it is another page on the same site and it assumes the domain name will be the same as the page we created the link on.

Relative links only include the file path to the other page *relative* to the page you are creating the link from.

To link to other pages (html files) in the same folder (at the same level) as the current page you can reference them like this

```html
<a href="about.html">About</a>
```

When the target webpage is in another directory of our project directory we'll need to go up a number of levels and navigate to the folder the webpage we're linking to is in.

If our current page was in the root directory of our project folder and the `about` page was in the `pages` folder we'd link like this:

```html
  <a href="pages/about.html">About</a>
```

This will tell the browser to link the `about` page in the `pages` folder. This does not work so it's best practice to use `./` like this:

```html
  <a href="./pages/about.html">About</a>
```

Projects can have many folders and the `./` in the above example show us moving up one level, then navigating to the pages folder, then the about.html file inside of it. Use as many `.` as is required to move up to the directory that you need to start moving back down into to navigate to folders (and any subfolders) required to reach the page you want to link to.

### Images

The **`<img>`** tag in HTML displays images. `<img>` is a **void element** meaning there is no closing tag and the element itself does not contain any content.

Instead of wrapping content with an opening and closing tag, it embeds an image into the page using a `src` attribute which tells the browser where the image file is located. It could be a file locally accessible in the project files (using a **relative** path) or a image hosted on another website (using an **absolute** path)

For example, this will render an image of the Odin logo hosted on The Odin Project's website:

```html
<img src="https://www.theodinproject.com/mstile-310x310.png">
```

Using a locally hosted image in our project files would look like this:

```html
<img src="../images/dog.jpg">
```

Using `../` as a relative link will tell the browser to move up, out of the current directory the current HTML page is in to navigate to where we are linking to, which in this case is the images folder.

#### Alt Attribute

There are two attributes that all images must have, `src` so the browser can find the file being embedded, and `alt` to contain the description of the image. There are many other attributes available on the the `img` element but these two are required. `alt` is required for two main reasons: it will be what is used in place of the image if it cannot be loaded and it is used by screen readers to describe what the image is to visually impaired users.

```html
<img src="../images/dog.jpg" alt="A portrait photo of a black Pug dog against a yellow background">
```

#### Image Size Attributes

While not required the first optional attribute you're likely to need is the image size attributes of `height` and `width`. It's best practice to specify these attributes on every image, even when the image is the correct size or also being modified by CSS. This prevents content jumping as images load. Use the image's actual dimensions when specifying size.

```html
<img src="../images/dog.jpg" alt="A portrait photo of a black Pug dog against a yellow background" height="853" width="640">
```

#### Knowledge check

- What element is used to create a link?
  - An anchor tag, `<a>` is used to create a link

- What is an attribute?
  - An attribute gives an HTML element additional information that affects content and presentation. For example `height` on a `img` element provides the height dimensions to the sourced file

- What attribute tells links where to go to?
  - the `href` attribute tells links where to go by using relative or absolute links

- What security considerations must be taken if you wish to use the target attribute to open links in a new tab/window?
  - `noreferrer` and/or `noopener` will limit what the new browsing tab/window will be able to see from the page that it was opened by

- What is the difference between an absolute and relative link?
  - Absolute links to other files and pages on the internet are called absolute links and will be made up of the following parts: `scheme://domain/path:port`. Relative links link to other files or pages locally sourced without having to go to external webpages

- Which element is used to display an image?
  - The `img` element embeds images in HTML

- What two attributes do images always need to have?
  - Image elements should always have a `src` attribute to link to the image to be embedded and a `alt` tag to provide the browser with a description of the image

- How do you access a parent directory in a filepath?
  - Using `./` in a file path will target the parent directory.

- What are the four main image formats that you can use for images on the web?
  - JPG, GIF, PNG and SVG
